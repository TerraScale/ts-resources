# ts-internals ADR index

The workspace [`GOAL.md`](../../GOAL.md) is authoritative. These records
capture product decisions that still help explain current code.

Current decisions cover public API compatibility, explicit project
capabilities, credential handling, audit retention, redaction, regional
routing, status reporting, usage integrity, deletion, and portable export.
Dashboard-owned identity and billing decisions live in the dashboard lane.
TerraBase protocol, placement, replication, storage, and backup decisions live
in the TerraBase lane.

When a record disagrees with the workspace goal, follow the workspace goal and
delete or rewrite the stale record. Git retains the old text when historical
research is needed.
