# ts-reviewer

`ts-reviewer` is not deployed. No review approval or reviewer status from this
project is required to merge. Do not request mariogk or the retired bot as a
reviewer, configure the old service, or follow its former deployment recipes.

Current source: [TerraScale/ts-reviewer](https://github.com/TerraScale/ts-reviewer).
Use GitHub PRs and Actions through `gh`; CI on GitHub-hosted runners is the
merge gate. Open ready-for-review PRs, never drafts. Address and answer every
reviewer finding, rebase on current main, and merge only when the exact latest
head is green. Use the T3 PR watcher while waiting for checks or reviews.

This resource snapshot does not deploy a GitHub review service. Any future
activation needs a separately verified implementation and deployment plan.
