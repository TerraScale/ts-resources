# TerraBase benchmark evidence

This context defines the language used to decide whether benchmark results can support TerraBase performance claims.

## Language

**Decision-grade benchmark run**:
A benchmark run that meets the required isolation, workload, identity, and review controls and may therefore support a performance decision.
_Avoid_: Benchmark result, test run

**Canonical baseline**:
An approved decision-grade result used as the comparison point for later performance decisions.
_Avoid_: Latest result, local baseline

**Performance claim**:
A customer-facing statement backed by an approved baseline for a named workload, payload, topology, and percentile.
_Avoid_: Fast, scalable
