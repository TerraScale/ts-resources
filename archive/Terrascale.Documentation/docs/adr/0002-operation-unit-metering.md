# Meter database work in 4 KiB operation units

TerraScale charges one operation unit for each started 4 KiB of uncompressed customer-document bytes. Reads and queries charge returned document bytes, with one unit for an empty successful query. Writes and updates charge once for the write in each selected region, so a write with three selected regions costs three times its document units and a write with five costs five times its document units. This multiplier includes the receiving region and every replication destination without a second replication charge. Batches round and sum each document separately, and deletes cost one unit per selected region. Rejected requests, server failures, internal retries, indexing, backups, monitoring, and internal repair do not add operation units during Public Alpha.
