# Limit data classes during Public Alpha

Public Alpha accepts ordinary application data and ordinary personal contact data. It prohibits credentials, cryptographic keys, payment-card data, health records, government identifiers, children's data, unlawful content, and workloads subject to special regulation. TerraScale does not need to inspect customer documents to state this contractual boundary, and it may widen the policy only after the matching legal, security, deletion, support, and incident controls exist.
