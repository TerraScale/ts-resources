# Expose typed public operations through MCP

MCP may expose every typed public operation available to the authenticated User, including Document, billing, credential, membership, and role-protected administration operations. It excludes private control-plane operations, private routes, and raw or generic HTTP forwarding. MCP uses a distinct user-bound access key with selectable Organization, Project, and operation scopes. Future Organizations and Projects are excluded by default. Sensitive actions use a server-enforced two-step flow that returns the exact plan, impact, price where relevant, and a five-minute single-use token. The User confirms in the AI conversation, and the AI invokes the confirmation tool. The server rechecks live permissions, tenant scope, canonical payload, target state, and price before atomically consuming the token and recording the Audit event. No Dashboard confirmation or separate fresh-authentication challenge is required.
