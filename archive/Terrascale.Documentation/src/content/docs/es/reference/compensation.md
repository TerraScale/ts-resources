---
title: Comportamiento de las asignaciones de Public Alpha
description: Asignaciones estrictas, reinicio mensual y reducción de uso durante Public Alpha.
---

Public Alpha usa asignaciones estrictas de almacenamiento y unidades de operación. Las unidades no utilizadas no se acumulan y la asignación se reinicia al comienzo del siguiente mes calendario.

TerraScale avisa cuando una organización se acerca a su límite. Cuando una nueva operación facturable superaría la asignación, se rechaza. Las lecturas, exportaciones de proyectos, eliminaciones y operaciones que reducen el uso siguen disponibles cuando el contrato lo permite. Public Alpha no ofrece excedentes pagados ni cobra la salida de datos.

Por ejemplo, si una organización Developer ha usado 9.999 de sus 10.000 unidades mensuales, una operación que necesita dos unidades se rechaza, pero una lectura o exportación permitida sigue disponible. El límite se reinicia el siguiente mes sin transferir unidades.
