# Show account security activity

TerraScale shows users a security activity page with the time, action, approximate location, client, and session for relevant events. It emails users about new provider links, MFA changes, password changes, recovery, and suspicious logins. Users may revoke individual sessions or sign out everywhere.

_Amended by [ADR-0041](0041-authenticate-terraScale-accounts-with-email-only.md): provider-link, MFA, and password-change events no longer exist. The events are email sign-ins, session creation and revocation, email changes, account suspension, and suspicious sign-ins._
